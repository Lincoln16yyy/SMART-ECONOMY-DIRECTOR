# SMART ECONOMY DIRECTOR

Planejador e coordenador econômico inteligente para Victoria 3, com versão alvo 1.15 informada pelo jogador.

O objetivo é analisar a economia nacional, definir prioridades de desenvolvimento e coordenar ações econômicas com transparência e proteções financeiras. A automação dependerá das capacidades comprovadas do jogo e da compatibilidade com os mods instalados.

## Estado atual

Projeto em preparação para a **Fase 0 — Pesquisa e diagnóstico**. Ainda não existe implementação do mod, instalação utilizável ou validação dentro do jogo.

A pesquisa deve começar pelo [Smart Government](https://github.com/Lincoln16yyy/Smart-Government-Victoria-3-1.15) e pelos arquivos reais do Victoria 3 e dos mods instalados. O Economy Advisor é a referência econômica indicada pelo jogador; não confundir com OGAS.

Não iniciar a implementação antes de concluir a pesquisa e apresentar o diagnóstico técnico e a arquitetura proposta, conforme a especificação.
